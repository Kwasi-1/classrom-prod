# Examples

- `hello-python/` — contents for a **template repository**. Create a repo in your org with these files
  and tick *Settings → Template repository*.
- `hello-python-tests/` — what to upload on the assignment page: paste `tests.yml`, and choose the
  `files/` folder as hidden test files (it contains `tests/test_main.py`, which ends up at
  `tests/test_main.py` in the student's tree).

The starter `add` raises `NotImplementedError`, so a fresh repo scores 0/50; a correct solution scores 50/50.
